# Защитное слово (3–4 минуты)

## Вступление (30 сек)

Здравствуйте, уважаемые члены комиссии. Меня зовут [ФИО], группа [группа].
Тема моей учебной практики — «Осуществление интеграции программных модулей».
В рамках практики я разработал учебную операционную систему StudyOS
с расширенной иерархической файловой системой на языке Python с
использованием SQLite.

## Цель и задачи (30 сек)

Цель работы — получить навыки проектирования, разработки, интеграции и
тестирования программных модулей. Для этого я решил четыре задачи:
спроектировал архитектуру из восьми модулей, реализовал функциональность,
интегрировал модули между собой и провёл полное тестирование.

## Архитектура (40 сек)

Система состоит из восьми модулей: `db` — работа с базой данных,
`kernel` — состояние системы, `auth` — аутентификация и права,
`fs` — иерархическая файловая система, `scheduler` — планировщик процессов,
`syscalls` — системные вызовы, `shell` — командная оболочка,
`logger` — логирование. Связи однонаправленные: оболочка вызывает системные
вызовы, те — ядро и подсистемы, подсистемы обращаются к базе данных.

## Функциональность (40 сек)

Реализовано управление пользователями с ролями `admin` и `user`,
иерархическая файловая система с командами `mkdir`, `touch`, `cat`, `write`,
`rm`, `rename`, `copy`, `move`, `tree`. Управление процессами: `run`, `ps`,
`kill`. Управление памятью с контролем лимита. Все системные вызовы
журналируются в таблицу `syscalls_log`.

## Тестирование (40 сек)

Проведено пять видов тестирования: модульное, функциональное,
интеграционное, системное и стресс-тестирование. Всего написано 55 тестов,
все проходят. Выполнено четыре системных сценария: первый запуск, работа
администратора, работа пользователя и восстановление после ошибок. Найдено
4 дефекта, все закрыты или отложены с обоснованием. Критичных дефектов нет.

## Демонстрация (30 сек)

Продемонстрирую работу системы. Запускаю оболочку, вхожу как администратор,
создаю файл, читаю его, запускаю процесс, завершаю его, смотрю состояние
памяти и журнал.

В результате практики я получил навыки проектирования модульных систем,
работы с SQLite, написания автоматических тестов и оформления технической
документации. Система готова к использованию. Спасибо за внимание, готов
ответить на вопросы.
