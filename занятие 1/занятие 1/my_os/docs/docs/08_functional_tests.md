# Функциональные тесты (день 8)

## Модуль fs.py (файловая система)

| ID | Функция | Что проверяем | Ожидаемый результат |
|----|---------|---------------|---------------------|
| FT-FS-01 | create_file | создание файла владельцем | возвращается id, запись в БД |
| FT-FS-02 | create_file | повторное создание того же пути | отклоняется (None/ошибка) |
| FT-FS-03 | create_file | владелец сохраняется верно | owner == переданный |
| FT-FS-04 | create_file | файл появляется в list_files | путь есть в списке |
| FT-FS-05 | read_file | чтение своего файла | содержимое совпадает |
| FT-FS-06 | read_file | чтение чужого файла | отказ (None/пусто) |
| FT-FS-07 | read_file | чтение несуществующего | отказ |
| FT-FS-08 | delete_file | удаление своего файла | запись удалена из БД |
| FT-FS-09 | delete_file | удаление чужого файла | отказ, запись остаётся |
| FT-FS-10 | list_files | список файлов владельца | содержит только свои файлы |

## Модуль scheduler.py (планировщик)

| ID | Функция | Что проверяем | Ожидаемый результат |
|----|---------|---------------|---------------------|
| FT-SCH-01 | add_process | добавление процесса | процесс в очереди |
| FT-SCH-02 | add_process | приоритет учитывается | порядок по приоритету |
| FT-SCH-03 | schedule | выбор следующего | возвращает корректный PID |
| FT-SCH-04 | schedule | Round Robin чередует | порядок циклический |
| FT-SCH-05 | remove_process | удаление процесса | процесса нет в очереди |
| FT-SCH-06 | remove_process | удаление несуществующего | без ошибок |
| FT-SCH-07 | get_state | состояние очереди | список PID |
| FT-SCH-08 | tick | счётчик квантов | увеличивается |
| FT-SCH-09 | reset | сброс планировщика | очередь пуста |
