# Итоговый протокол тестирования

## 1. Тестируемая система
Учебная операционная система StudyOS. Реализована на Python 3.10 с
использованием SQLite. Состоит из модулей: db.py, kernel.py, auth.py,
fs.py, scheduler.py, syscalls.py, shell.py.

## 2. Объём тестирования
- Модульное тестирование: db.py, kernel.py, auth.py.
- Функциональное тестирование: fs.py, scheduler.py, syscalls.py.
- Интеграционное тестирование: связки shell → syscalls → fs,
  shell → syscalls → scheduler, syscalls → auth → db.
- Системное тестирование: четыре сквозных сценария (SS-01 — SS-04).
- Стресс-тестирование: 10 процессов, 50 файлов, 20 пользователей.
- Регрессионное тестирование: три прогона после исправлений.

## 3. Метрики
- Всего тестов: 55.
- Пройдено: 55 (100%).
- Провалено: 0.
- Дефектов найдено: 4.
- Дефектов исправлено: 3.
- Дефектов отложено: 1.
- Дефектов открыто: 0.

## 4. Результаты по сценариям

### SS-01: Первый запуск ОС
Метод: удаление базы, запуск `python src/db.py`, проверка через SQLite Viewer.
Результат: база создана, шесть таблиц присутствуют, роли заполнены.
Статус: пройден.

### SS-02: Работа администратора
Метод: запуск `python -m src.shell`, выполнение сценария администратора.
Результат: файлы созданы, процессы запущены и завершены, память
освобождена, журнал заполнен.
Статус: пройден.

### SS-03: Работа обычного пользователя
Метод: запуск оболочки, выполнение сценария пользователя.
Результат: свои действия разрешены, чужие запрещены, отказы записаны
в syscalls_log со статусом DENIED (минимум 2 записи).
Статус: пройден.

### SS-04: Восстановление после ошибок
Метод: запуск оболочки и провокация ошибок (неверный пароль,
несуществующий файл, дубликат).
Результат: система обрабатывает ошибки без падения.
Статус: пройден.
